# Contributing

Off-Grid Survival Shelf is shared as-is, without guaranteed maintenance or support.
You're welcome to fork it and make changes. Issues and pull requests may not
receive a response.

Run the tests on macOS or Linux with Python 3.8 or newer:

```bash
python3 -m unittest discover -s tests -v
```

Please do not include downloaded books, personal files, or credentials in a
contribution.
